EDIO 72/46 IO Module

FEATURES

EDIO 72/46 Features

  • 01EtherCAT-based, easy to connect, and freely combinable with other function modules
  • 0272 input contacts and 46 output contacts, with COM configured in 8-contact groups
  • 03Inputs can be selected as bidirectional (N24/P24), outputs as unidirectional (N24)
  • 04Built-in spindle output port, MPG output port, and encoder input port support a wide range of applications
