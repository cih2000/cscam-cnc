Single-Axis Controller Configuration
FEATURES

Single-Axis Controller Features

The SDC SERIES enables a variety of motion and positioning control without a motion controller.

Positioning control is performed inside the drive, enabling a cost-effective control system configuration.

Control is possible with I/O contacts alone, or the unit can connect to an upper-level controller (PLC, etc.) via MODBUS communication.

  • 010.2kW ~ 3kW Servo Drive
  • 0219/16 I/O, contact-based control method
  • 03Precise position and speed control
  • 04Home setting, forward/reverse JOG operation
  • 05Equal-division operation, fine-increment operation
  • 06Short-distance operation in a rotational coordinate system
