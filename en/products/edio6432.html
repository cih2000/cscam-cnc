EDIO 64/64, 32/32 IO Module

Connector cable type, expandable in 32/32 increments.

  • I/O contacts are organized in 16-point COM groups and can be freely expanded in 32/32 increments to match the required contact count.

FEATURES

EDIO 64/64, 32/32 Features

  • 01EtherCAT-based, easy to connect, and freely combinable with other function modules
  • 02EDIO 64/64 provides 64 inputs · 64 outputs; EDIO 32/32 provides 32 inputs · 32 outputs
  • 03COM is configured in 16-contact groups; inputs can be selected as bidirectional (N24/P24), outputs as unidirectional (N24)
  • 04IO can be expanded in 32/32 increments
