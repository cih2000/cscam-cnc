FEATURES

EDIO IN32, OUT32, IN16/OUT16 Features

  • 01EtherCAT-based, easy to connect, and freely combinable with other function modules
  • 02EDIO IN32 provides 32 inputs, EDIO OUT32 provides 32 outputs, and EDIO IN16/OUT16 provides 16 inputs · 16 outputs
  • 03COM is configured in 16-contact groups; inputs can be selected as bidirectional (N24/P24), outputs as unidirectional (N24)
  • 04IO expansion can be selected independently for input or output as needed
