FEATURES

StepSERVO Motor & Drive 특징

  • 01DC 파워 +24V ~ +48V 사용
  • 02Open-Loop / Closed-Loop 두가지 방식으로 사용 가능
  • 03모터에 장착된 고정도 엔코더를 통해 현재의 위치를 파악함으로 탈조 현상이 없음
  • 04엔코더 피드백으로 항상 현재 위치를 체크하여 최적의 위치보정
  • 05손쉬운 게인 조정으로 저강성 부하에서도 최적 성능 발휘
  • 06부하 시 자동으로 전류를 조절하여 모터효율을 극대화
  • 07열 손실을 최대 80%까지 감소시켜 장비감도와 신뢰성을 향상
  • 08과전압, 과전류, 과온도, 상쇼트 검출
