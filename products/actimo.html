05-1 / ACTIMO — 구성 및 특징
ACTIMO 시스템 구성
FEATURES

ACTIMO 특징

  • 01티칭펜던트 활용 단축제어기
  • 02한 손에 잡히는 티칭 펜던트로 현장에서 위치 티칭/시운전 가능
  • 03유공압 실린더를 전동 실린더로 1:1 대체 가능
  • 04ACTIMO Setup SW로 단축제어기 모든 셋업 지원
  • 05StepSERVO, BLDCservo 드라이브 여러대 동시연결 가능
  • 06RS-485통신으로 최대 16축까지 연결 가능
  • 07제어 변수(파라미터, ACTION Table, 튜닝값)를 파일로 관리
05-2 / ACTIMO — PROGRAM
ACTIMO PROGRAM
SOFTWARE

ACTIMO Motion Table 기능

  • 01Action List 255 Points로 충분한 용량 확보
  • 02외부 DIO 접점 (In 20/Out 12)으로 상위 PLC 연결
  • 03외부 버튼입력으로 동작 지령 및 분기(Goto) 가능
  • 04특정 Action List 도달 후 출력접점으로 상태 보고(Output) 가능
  • 05임의원점 설정, 부하원점 설정 기능으로 유사 실린더 동작지원
  • 06토크모드 동작 지원
